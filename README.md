# Sistema de Feedbacks dos Alunos

Projeto desenvolvido com Node.js e Express.js para cadastrar, listar e remover feedbacks de alunos.

## Funcionalidades

- Cadastro de feedback com nome e comentário.
- Listagem dos feedbacks cadastrados.
- Remoção de feedbacks.
- Armazenamento dos dados em memória utilizando um array.

## Tecnologias utilizadas

- Node.js
- Express.js
- HTML
- JavaScript

## Como executar

1. Instale o Node.js.
2. Clone este repositório.
3. Instale as dependências:

   `npm install`

4. Inicie o servidor:

   `node app.js`

5. Acesse `http://localhost:3000` no navegador.

**Observação:** os feedbacks são armazenados apenas em memória e são perdidos quando o servidor é reiniciado.
